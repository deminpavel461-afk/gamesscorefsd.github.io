# GamesScoreFSD

Веб-приложение учёта игр со статистикой игроков и таблицей выплат.

## Запуск

1. Установите [Node.js LTS](https://nodejs.org/)
2. В папке проекта выполните:

```bash
npm start
```

или дважды кликните `start.bat`.

3. Откройте [http://localhost:3000](http://localhost:3000)

## Админ

- Логин: `Володя Гаврилюк`
- Пароль: `admin`

## API

| Метод | Путь | Доступ | Описание |
|-------|------|--------|----------|
| GET | `/api/state` | все | игроки, игры, выплаты, текущий пользователь |
| POST | `/api/auth/login` | все | вход, возвращает token |
| POST | `/api/auth/logout` | авторизованный | выход |
| GET | `/api/auth/me` | авторизованный | текущий пользователь |
| POST | `/api/games` | админ | добавить игру |
| PUT | `/api/games/:id` | админ | изменить игру |
| DELETE | `/api/games` | админ | очистить игры |
| PUT | `/api/payouts` | админ | сохранить таблицу выплат |

Данные хранятся в `server/data/db.json`.
